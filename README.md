# Igor ist krank – Webseite

Eine einzige Datei: `index.html`. Doppelklick öffnet sie im Browser.

## Bearbeiten
- Mit einem Texteditor öffnen (z. B. VS Code oder TextEdit im Modus «Reiner Text»).
- Platzhalter suchen und ersetzen: `[PREIS]`, `[GEBIET]`, `[UHRZEIT]`, `[LIEFERDIENST]`, `[FIRMA]`, `[NAME]`.
- Die Knöpfe «Hier bestellen» und «Über [LIEFERDIENST]» zeigen noch auf `#`. Dort später den echten Bestell-Link eintragen.

## Farben
- Suppengelb (Hintergrund): `#FFE9A8`
- Tomatenrot (Akzent): `#C8241B`
- Tinte (Text, Konturen): `#1E1A17`
- Pyjamablau: `#9CC9EE`

## Schriften
Fredoka (Titel) und Nunito (Text), geladen von Google Fonts. Ohne Internet fällt die Seite auf die Systemschrift zurück.

## Online stellen
Den ganzen Ordner auf einen Webspace laden, z. B. Netlify, GitHub Pages oder den Hoster einer eigenen Domain.
